# TURBO1000 UNLOCK — 2026-11-16

- Native Gamma experimental profile1000 отдельно от stock800. Штатная разблокировка теперь доступна; OVERCLOCK сохраняет разрешение, не выставляет частоту/напряжение и не запускает поиск.
- Согласованы native gates, API, ручная форма и stock tuner.900MHz/30W принимаются после unlock;1001MHz/1301mV/31W отклоняются до изменения настроек.
- Удалён фиксированный25W TURBO. ПаспортныеW/A БП сохраняются, бюджет рассчитывается по мощности/току/reserve/погрешности/VIN/температуре.5V6A30W→25.5W,40W8A→30W; пользовательский максимум всегда30W.
- Реальные ступени PLL12.5MHz с legacy округлёнными метками, повторные измерения, поиск минимального стабильного напряжения10mV, выбор ACK-adjusted hardware score вместо максимальной частоты; карта/история испытаний и best point.
- Бюджет измерительного окна обновляется каждую секунду; изменённый PSU/лимит не ждёт конца600s окна. Критическое превышение паспортной мощности/тока ведёт к штатному emergency shutdown; Safe Recovery сначала сбрасывает расширенную точку.
- UI «Разгон» объединяет штатную разблокировку с TURBO; один power input, реальные API limits, бюджет/причина/прогресс/карта/история. Исправлен конфликт имён кнопок start/stop внутри form.
- Unlock/PSU/user cap сохраняются; corrupt PSU config закрывает расширенный режим. Boot/выключение/неудачный откат возвращают stock safe point; эксперимент сам не возобновляется.
- Исходные68/80°C ASIC,85/100°C VRM,1300mV и flash/bootloader protections сохранены. Hunter/Guardian/Network/Benchmark не менялись. Hardware/прирост не проверены.

# ULTIMATE2.0 TURBO1000 — 2026-11-13

База23724c5/Ultimate2.0. Gamma601, один BM1370, ESP-IDF5.3.2.

- Ручное подтверждение TURBO1000; максимум поиска800..1000MHz шаг25, запрос мощности18..30W. Активация не сохраняется и не устанавливает максимальную частоту принудительно.
- Единственный штатный tuner исследует от свежей стабильной точки; map16 измеренных точек,120s прогрев/300s окно, проверка принятой работы, сессии и аппаратных счётчиков. Нестабильность вызывает откат, сбой записи PLL — консервативный возврат к штатной точке либо отключение питания при неудаче.
- Решатель PLL проверен против оригинала; выше800 используются точные12.5MHz ступени с задержкой200ms, прежняя скорость изменения сохранена. Legacy806.25 не был неподдерживаемым: он вычислял приближённую частоту.
- Gamma TPS546 оценивает входную мощность косвенно. Запрос30W ограничен рабочим бюджетом<=25W; резерв3W, дополнительное снижение<=23W при нагреве/просадке/неопределённом PSU.30W не является целевой нагрузкой.
- Сохранены800MHz по умолчанию,1300mV максимум и исходные аварийные68°C/85°C; экспериментальные проверки строже. Параллельное изменение настроек/пулов/OTA/Benchmark блокируется до остановки.
- Исправлены устаревшая частота после частичного PLL failure, продолжение voltage/clock sequence после неудачной записи, обновление свежести мощности при ошибочных reads и потеря ручного stop при переходе в удержание.
- UI3: разблокирован ручной TURBO, предел1000, видимый derated budget, карта и причины завершения: частота/мощность/температура/питание/ошибки/PLL/1300mV/сеть/датчики/память.
- Flash layout, bootloader source, NVS настроек, кошелёк, пулы, Stratum, Hunter/Block Guardian/Network Guardian/Benchmark и штатные безопасные профили сохранены. Аппаратных измерений и заявления прироста нет.

# BTC HUNTER ULTIMATE2.0

База: Ultimate1.0/commit237d3f7 + AxeForge1.4.10/e84c651; ESP-IDF5.3.2, Gamma601/BM1370.

- Полностью исключены native Weather/Open-Meteo и Mempool polling: нет их HTTP/TLS задач. NTP сохранён отдельной завершающейся задачей; ручное UTC-смещение хранится отдельно, город/настройки остаются в NVS.
- Отключены фоновая рыночная цена/автопауза по цене и автоматические проверки/установка внешней прошивки. Ручной тариф/учёт энергии и ручная OTA сохранены. Guardian explorer вызывается только явным запросом.
- Farm не опрашивает сеть по таймеру. Кэш обновляется по запросу клиента с интервалом не чаще15s; сканирование только вручную.
- TCP keepalive60/20/3; предел отсутствия данных180s для используемого пула,900s для standby. Добавлены события connect/read/write/idle/malformed, счётчики reconnect, socket uptime/downtime, processing latency и minimum internal heap.
- Ошибка write/restart больше не обходит backoff; предел60s, сброс до2s после300s здоровой сессии. Возврат на восстановившийся основной пул требует30s готовности; аварийный failover немедленный.
- При разрыве валидного аппаратного счётчика сбрасывается связанная error-counter baseline. Исправлена воспроизводимая ложная underflow-ошибка; корректный wrap и реальные errors сохранены.
- Единственный штатный tuner, прежние стабильные точки/rollback, Power/Thermal Guardian, watchdog, self-test и OTA Guard сохранены. Автоматический tuning envelope ограничен25W. Новые запросы>25W отклоняются до изменения настроек; сохранённый профиль не стирается.
- ECO18W, BALANCED22W, BTC HUNTER25W. TURBO до30W виден, но заблокирован до аппаратной валидации.
- Тёмный русский UI2.0: отдельные ASIC/принятая работа и двухцветный график, состояние единого AXE Intelligence, диагностика сети, прежние4вкладки/13шкал/OTA/журнал. Статус5s, дополнительные API15s только на нужных видимых страницах.
- Добавлены ASan/UBSan production tests для счётчика, reconnect, services, tuning guard, NTP/NVS и сетевой статистики; API/OpenAPI и Chromium/WebKit обновлены. Воспроизводимые патчи и резервный Ultimate1.0 сохранены.

Защиты, регистры/baud, flash/bootloader и Wi-Fi/wallet/pool settings не расширены/не стираются. Измеренного аппаратного прироста нет; TEST-REPORT.md содержит реальные результаты и ограничения.
