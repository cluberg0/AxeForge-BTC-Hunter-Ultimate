# BTC HUNTER ULTIMATE2.0

База: Ultimate1.0/commit237d3f7 + AxeForge1.4.10/e84c651; ESP-IDF5.3.2, Gamma601/BM1370.

- Полностью исключены native Weather/Open-Meteo и Mempool polling: нет их HTTP/TLS задач. NTP сохранён отдельной завершающейся задачей; ручное UTC-смещение хранится отдельно, город/настройки остаются в NVS.
- Отключены фоновая рыночная цена/автопауза по цене и автоматические проверки/установка внешней прошивки. Ручной тариф/учёт энергии и ручная OTA сохранены. Guardian explorer вызывается только явным запросом.
- Farm не опрашивает сеть по таймеру. Кэш обновляется по запросу клиента с интервалом не чаще15s; сканирование только вручную.
- TCP keepalive60/20/3; предел отсутствия данных180s для используемого пула,900s для standby. Добавлены события connect/read/write/idle/malformed, счётчики reconnect, socket uptime/downtime, processing latency и minimum internal heap.
- Ошибка write/restart больше не обходит backoff; предел60s, сброс до2s после300s здоровой сессии. Возврат на восстановившийся основной пул требует30s готовности; аварийный failover немедленный.
- При разрыве валидного аппаратного счётчика сбрасывается связанная error-counter baseline. Исправлена воспроизводимая ложная underflow-ошибка; корректный wrap и реальные errors сохранены.
- Единственный штатный tuner, прежние стабильные точки/rollback, Power/Thermal Guardian, watchdog, self-test и OTA Guard сохранены. Автоматический tuning envelope ограничен25W. Новые запросы>25W отклоняются до изменения настроек; сохранённый профиль не стирается.
- ECO18W, BALANCED22W, BTC HUNTER25W. TURBO до30W виден, но заблокирован до аппаратной валидации.
- Тёмный русский UI2.0: отдельные ASIC/принятая работа и двухцветный график, состояние единого AXE Intelligence, диагностика сети, прежние4вкладки/13шкал/OTA/журнал. Статус5s, дополнительные API15s только на нужных видимых страницах.
- Добавлены ASan/UBSan production tests для счётчика, reconnect, services, tuning guard, NTP/NVS и сетевой статистики; API/OpenAPI и Chromium/WebKit обновлены. Воспроизводимые патчи и резервный Ultimate1.0 сохранены.

Защиты, регистры/baud, flash/bootloader и Wi-Fi/wallet/pool settings не расширены/не стираются. Измеренного аппаратного прироста нет; TEST-REPORT.md содержит реальные результаты и ограничения.
