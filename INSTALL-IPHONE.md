# TURBO1000 UNLOCK — iPhone OTA и откат

Только Gamma601/ESP32-S3/один BM1370. Скачайте `axeforge-gamma-BTC-HUNTER-TURBO1000-UNLOCK.bin` и SHA256SUMS.txt. ZIP в «Файлах» распаковывается касанием. SHA скачанного app при возможности сверяется локальным SHA-256 инструментом; файл суммы сам по себе не проверяет загрузку.

1. iPhone в той же LAN → Safari → адрес майнера. Сохраните backup настроек, адрес/кошелёк/пулы и свой проверенный Gamma app для отката. OTA Guard оставить включённым.
2. Если есть активный поиск, нажмите «Остановить и вернуть штатный режим», дождитесь завершения. Затем отключите расширенный разгон и дождитесь штатных525MHz/1150mV. Не выполняйте OTA одновременно с экспериментом.
3. «Система» → обновление прошивки → «Обзор»/«Файлы» → точный app `.bin`. Пройдите штатную2FA. Не закрывайте Safari и не отключайте сеть/питание до перезагрузки. ZIP/ELF/factory/bootloader/partitions не загружать в OTA.
4. После запуска проверьте версию `1.4.10-hunter-TURBO1000-UNLOCK`, Gamma/один BM1370, Wi-Fi/кошелёк/пулы/вентилятор/настройки. NVS/bootloader/таблица разделов app OTA не стираются/не переписываются. Первую проверку проведите на прежних безопасных настройках без экспериментов; дождитесь штатного OTA Guard probation и свежей телеметрии.

## Разблокировка и поиск

«Разгон» → «Включить расширенный разгон» → OVERCLOCK. Разрешение сохраняется, максимум автоматически не применяется. Native limits должны показать1000MHz/<=1300mV/user<=30W при исправном PSU. Слабый PSU приостанавливает расширенные частоты; причина/фактический бюджет видны.

Введите фактические паспортныеW/A БП(для5V/6A —30W/6A). Не вводите40W/8A без реальной замены БП. Задайте пользовательский лимит в единственной штатной форме, максимум поиска800..1000MHz, сохраните параметры БП/поиска. Бюджет включает10% мощности(>=2W),0.5A и1.5W погрешности оценки;25.5W на30W/6A и30W на40W/8A до derating. Это не обещание безопасных30W на вашей плате.

Ручная частота>800 доступна после unlock через штатную форму с выключенным автотюнером. Нужны свежие исправные датчики/охлаждение/питание и поддерживаемая PLL; ошибки вызывают возврат к stock точке. Для автоматического поиска нужны stock tuner Locked,30min стабильности,>=100ACK, V1 failover и отсутствие Benchmark. «Подтвердить и начать» → TURBO1000; «Перезапуск поиска» использует тот же контур и те же условия.1000 — потолок, не цель. Измерения каждой ступени повторяются, минимальное напряжение проверяется; при высокой сложности шар данных может не хватить и поиск прекратится.

Начинайте испытание под наблюдением с небольшого максимума825MHz и своих подтверждённых параметров. Не обходите отказ/аварийные пороги. Физическое тестирование этой сборки не проводилось. Изучите HARDWARE-TEST-PLAN.md.

Разрешение/БП/user cap переживают reboot, поиск не возобновляется. Если сохранённая частота была>800, boot возвращает runtime к stock525/1150 до нового ручного решения; Wi-Fi/wallet/pools сохраняются. Данные PLL — вычисленная конфигурация после команды драйверу, не физический readback/измерение частоты.

## Откат

Остановить поиск → отключить расширенный разгон → дождаться stock точки → через тот же OTA раздел загрузить свой проверенный Gamma app. В комплекте backup/axeforge-gamma-BTC-HUNTER-ultimate-2.0-TURBO1000.bin + отдельный SHA256SUMS; его программные проверки прошли ранее, аппаратная работоспособность у пользователя не подтверждена. Новые данные af_turbo старой прошивкой могут игнорироваться; NVS стирать не требуется. Пулы/кошелёк/Wi-Fi сохраняются, backup импортировать лишь при необходимости.

OTA Guard может откатить неисправный app при штатных условиях, но не исправляет любой отказ. При полном отсутствии запуска и OTA понадобится отдельное аппаратное восстановление по USB/ПК; обычная установка с iPhone этого не требует.
