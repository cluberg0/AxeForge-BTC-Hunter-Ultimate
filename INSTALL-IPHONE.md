# Установка с iPhone и откат

Используйте только app-файл `axeforge-gamma-BTC-HUNTER-ultimate-2.0.bin`, предназначенный для Bitaxe Gamma 601 с одним BM1370. ZIP исходников, ELF, bootloader, partition-table и factory-образы в OTA не загружать.

Перед установкой прочитайте TEST-REPORT.md: сборочные и программные проверки не заменяют испытания на вашем ASIC. Физический Bitaxe в этой среде недоступен.

1. Подключите iPhone к той же локальной сети, что Bitaxe. В Safari откройте текущий адрес майнера. Экспортируйте резервную копию настроек в «Файлы». Запишите адрес устройства и сохраните отдельный заведомо рабочий **Gamma app OTA** для отката. Проверьте кошелёк, worker, оба пула, Wi-Fi и включённый OTA Guard. Новые архивы `af_intel`/`af_hunter` штатным экспортом настроек не экспортируются.
2. Скачайте предоставленный `.bin` в «Файлы». Если скачали ZIP комплекта или GitHub Actions artifact `Gamma-BTC-Hunter-OTA`, коснитесь ZIP в «Файлах», чтобы распаковать. Рядом находится SHA256SUMS.txt. Для сверки на iPhone можно использовать доверенный локальный инструмент SHA-256/команду «Быстрых команд», если она у вас есть; наличие файла суммы само по себе не означает, что загрузка проверена.
3. Откройте Bitaxe → «Система» → обновление прошивки. Выберите `.bin` через «Обзор» → «Файлы». Подтвердите загрузку; при включённой 2FA авторизуйтесь штатным способом. Не отключайте питание, Wi-Fi или Safari во время загрузки. Не запускайте параллельное обновление.
4. После перезапуска обновите страницу Safari. Проверьте версию `1.4.10-hunter-ultimate-2.0`, плату Gamma, кошелёк/worker, пулы, Wi-Fi и сохранённые настройки. Обновление app не стирает NVS и не меняет разделы. Если OTA Guard сообщил о возврате к предыдущей версии, изучите журнал; не отключайте guard ради обхода ошибки.
5. Первый аппаратный запуск проводите под наблюдением, на ранее проверенных настройках с лимитом 25 Вт и автономными опциями выключенными. Не выбирайте профиль «Максимум 30 Вт» для первого испытания. Следите за ASIC, VRM, RPM, питанием, ошибками, accepted/rejected, памятью и журналом. Проверьте `/api/intelligence` после NTP, накопление истории с закрытым Safari и сохранение после перезапуска. Автообдув, возврат режима и Timing Optimizer включайте по отдельности после проверки стабильности.
6. Для ручного отката при работающем веб-интерфейсе загрузите сохранённый рабочий Gamma app через тот же раздел OTA. Пулы/кошелёк/Wi-Fi должны сохраниться; резервную копию импортируйте лишь при необходимости. Штатный OTA Guard может сам вернуть прежний образ при заданных upstream условиях, но не гарантирует восстановление при любой неисправности. Если устройство вообще не загружается и OTA недоступна, потребуется отдельная процедура аппаратного восстановления; обычная установка ПК/USB не требует.

Не путайте локальный кандидат блока, ответ accepted пула и подтверждение Bitcoin в цепочке. Разрыв соединения может лишить отправку ответа; прошивка не обещает гарантированную доставку и не повторяет кандидата на другом пуле.

После первоначальной проверки Benchmark Lab запускается только вручную и занимает около 3,5 часа (шесть этапов, прогрев включён). Guardian сети также включается отдельно: он передаёт публичный хеш кандидата сервису mempool.space по HTTPS. Эти функции для первой OTA-проверки оставьте выключенными.

В2.0 после OTA проверьте «Часы»: UTC-смещение600мин для Уссурийска. Weather/Mempool/market feeds отключены; старые поля настроек сохранены. TURBO30W недоступен, automatic tuning ceiling25W. Для отката используйте свой реально проверенный Gamma OTA либо файл backup/axeforge-gamma-BTC-HUNTER-ultimate.bin из комплекта (последний прошёл программные проверки, не физическое испытание). Откат через работающий web UI также не стирает Wi-Fi/wallet/pools. Новый namespace af_clock останется неиспользуемым в1.0.
