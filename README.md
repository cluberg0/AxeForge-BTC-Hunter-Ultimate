# AxeForge BTC Hunter Ultimate · Gamma 601

> **Исходный инженерный проект, а не проверенная прошивка.** Не загружайте ZIP в OTA. ESP32-S3 сборка и тестирование на реальном Bitaxe Gamma 601 пока не подтверждены.

Основа: [AxeForge v1.4.10](https://github.com/IsSasoriDev/AxeForge/tree/v1.4.10), commit `e84c651c36a4b5f91c537577704245ded032592d`, лицензия GPL-3.0.

Цель: улучшить *реальную принятую BTC-работу за сутки* на одном BM1370, не обещая волшебного увеличения вероятности блока. В проекте подготовлены русская панель, мониторинг пулов и задержек, журнал кандидатов блока, анализ уникальности работы, осторожные эксперименты с интервалами заданий, наблюдение за температурой и откат настроек.

## Важно: пакет исходников ещё нужно добавить

Подготовленный пакет называется **`AxeForge-Codex-Complete.zip`**. Он содержит 45 файлов: `AGENTS.md`, `TASK.md`, `HANDOFF-TESTS.md`, `overlay/`, `scripts/`, `tests/`, `apply.py`, `verify_image.py` и workflow.

После загрузки **распакуйте содержимое ZIP в корень репозитория** (не храните только ZIP), чтобы GitHub Actions видел `scripts/prepare.sh`, `scripts/test.sh`, `scripts/build.sh`. Пока этих файлов нет, запуск сборки недоступен.

## Безопасность

- Профиль 30 Вт не означает безопасную непрерывную работу на штатном БП 30 Вт.
- Не поднимать напряжение/частоту сверх проверенных аппаратных ограничений без отдельных испытаний.
- Не прошивать устройство до успешной сборки, проверки бинарника и наличия резервного OTA.
- Программные unit-тесты не заменяют испытания на реальном оборудовании.
